家電の説明書というのは、なぜかいつも必要なときに見当たらない。

「食洗機のお手入れ方法」を調べたいだけなのに、説明書の束をひっくり返し、見つかったと思ったら別の機種のもので、結局メーカーのサイトで検索し直す。うちではそんなことが何度もあった。

説明書はスキャンしてNASに保存してあった。データとしては手元にあるのに、必要なときに引き出せない。ただ保管してあるだけでは意味がない、とずっと思っていた。

そこでIrisに頼んでみた。

「家にある説明書を、聞いたらすぐ答えてくれるようにして」

具体的にどう検索するか、どんな仕組みにするかは何も指定していない。伝えたのはそれだけだった。

## Irisが作ったのは、家専用の「索引」

出来上がったのは、保存してある説明書(PDFやメモ)を全部読み込んで、質問したときにすぐ該当ページを引っ張り出せるようにする、家専用の検索の仕組みだった。

ポイントは2つある。

1つ目は、**元のファイルには一切手を加えないこと**。説明書そのものはNASに置いたままで、検索用の索引だけを別に作る。索引を作り直しても、元のデータは触らない。

2つ目は、**答えには必ず「どの資料の何ページか」が付いてくること**。AIが適当に答えを作文するのではなく、実際にその説明書に書いてあった箇所を根拠として示す。数字や注意書きのような重要な部分は、答えを鵜呑みにせず元のページで確認する、というルールも一緒に組み込まれていた。

## 「同じもの」をAIに教える必要があった

作業を進める中で、想定していなかった問題が出てきた。

うちにある説明書は、メーカーによって同じものを違う呼び方で書いていることに気づいたのだ。たとえば「食洗機」を、ある説明書は「食器洗い乾燥機」、別の説明書は「食器洗浄機」と呼んでいる。「お手入れ」も、説明書によっては「手入れ」「清掃」「メンテナンス」とバラバラだ。

そのままでは、「食洗機」で検索しても「食器洗浄機」としか書いていない説明書はヒットしない。人間なら読めば同じことだとわかるが、検索の仕組みはそうはいかない。

これに対してIrisは、よくある言い換えのグループをあらかじめ用意しておき、どの呼び方で聞いても同じ意味として扱う仕組みを自分で組み込んでいた。「食洗機で聞いても食器洗い乾燥機の説明書がちゃんと出てくる」というのは、頼んだときには思いつきもしなかった配慮だった。

## 聞き方は雑でいい

実際に使ってみると、一番変わったのは「調べ方」だった。

以前は、まずどの説明書を見るべきかを自分で判断してから、その説明書を開いて該当ページを探す、という順番だった。今は「食洗機のお手入れ方法」とそのまま聞くだけでいい。どの説明書のどのページに書いてあるかを、Iris側で見つけてくれる。

説明書を探す時間そのものがなくなった、というのが率直な感想だ。

## 頼んだのは一言、形にしたのはIris

今回も、私がやったのは「説明書をすぐ引き出せるようにしてほしい」と伝えたことだけだった。索引の作り方も、元データを守る設計も、呼び方の違いを吸収する仕組みも、すべてIrisが自分で考えて実装した。

家にあるものを家の中だけで検索できるようにする——地味だけれど、暮らしの中では確実に時間を生んでくれる仕組みだった。次にまた「あれ、どこだっけ」と思ったときのために、こうやって一つずつ、聞けば答えてくれる仕組みを増やしていきたい。

| 表記のばらつき | 意味 |
| --- | --- |
| 食洗機 / 食器洗い乾燥機 / 食器洗浄機 / 食器洗い機 | 同じ家電を指す |
| エラー / 異常 / 故障 / 警告 | 同じ状態を指す |
| お手入れ / 手入れ / 清掃 / 掃除 / メンテナンス | 同じ作業を指す |
| 設置 / 取付 / 取り付け / 据付 | 同じ作業を指す |
